Скрипт создаст файл с отметкой времени последнего запуска. При следующем запуске
будут анализироваться только записи, появившиеся после этой отметки:
```bash
$ ls -lA .
...
-rw-rw-r-- 1 rzaitov rzaitov     26 Nov  6 19:30 .report.sh.timestamp
```

Путь к файлу с отметкой времени можно задать с помощью параметра
`--timestamp-file`. Параметр `--top` задаёт количество IP-адресов и URL,
которые попадут в соответствующие разделы отчета (по умолчанию 10):
```bash
$ ./report.sh --top 5 --timestamp-file /tmp/.timestamp /var/log/nginx/access.log
```

## Refs

Для написания awk скрипта я прочитал 7 и частично 8 и 9 главы книги "sed & awk".
Важно передавать `TZ=UTC` перед вызовом awk. В используемой мной реализации awk
(`mawk`) функция `mktime()` интерпретирует дату в часовом поясе текущего процесса
и не поддерживает отдельный параметр для использования UTC. Например, на моём
компьютере используется часовой пояс `+01:00`, тогда как в записи nginx может
быть указан другой часовой пояс, например, `+03:00`. Поэтому я написал функцию,
которая преобразует локальное время из записи nginx в Unix timestamp с учётом
указанного в логе смещения часового пояса.

Наверное, в идеале отчёт стоило бы полностью формировать с помощью awk за один
проход, а не выполнять отдельный вызов awk для каждой секции, как это реализовано
сейчас. Но я уже потратил на эту задачу несоразмерно много времени, поэтому пока
оставил всё как есть.

Так же я впервые использовал `getopt`, до этого я использовал `getopts` но там
невозможно просто реализовать поддержку длинных опций, как например `--top`. С
